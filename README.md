# LionKingFlag

Codebook of NTU LionKingFlag forked from 8BQube

[Codebook PDF (latest `master`)](https://github.com/GrandTiger1729/codebook/releases/download/latest/codebook.pdf)
— rebuilt by CI on every push to `master`, so this link always gives the newest version.
A PR's PDF is under its CI run's Artifacts instead.

Tests live in [`verify/`](verify/README.md).


Compile Commands:
```
cd codebook
xelatex --shell-escape codebook.tex
```
