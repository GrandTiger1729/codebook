Given $F(x) = \sum_{i=0}^{\infty} \alpha_i (x - \beta)^i$ for some constant $\beta$, a polynomial $P$ with $F(P) = 0$ can be found iteratively. If $Q_k$ satisfies $F(Q_k) \equiv 0 \pmod {x^{2^k}}$, then

$$ Q_{k+1} = Q_k - \frac{F(Q_k)}{F^\prime(Q_k)} \pmod {x^{2^{k+1}}} $$
